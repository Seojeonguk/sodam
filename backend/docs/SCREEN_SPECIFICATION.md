# Sodam 화면 정의서

## 문서 목적

이 문서는 현재 프론트엔드에 구현된 화면과 사용자 인터랙션을 기준으로 화면별 목적, 진입 조건, 주요 기능, 연동 API를 정리한다.

## 화면 목록

| Route | 화면 | 인증 | 설명 |
| --- | --- | --- | --- |
| `/` | 로그인 | 불필요 | 이메일/비밀번호 로그인 |
| `/signup` | 회원가입 | 불필요 | 신규 사용자 등록 |
| `/dashboard` | 대시보드 | 필요 | 가계 요약 및 통계 |
| `/transactions` | 거래 내역 | 필요 | 거래 조회/생성/상세/수정/삭제 |
| `/category` | 카테고리 관리 | 필요 | 카테고리 및 분류 관리 |

## 공통 레이아웃

### 인증 라우트

`/`, `/signup`은 `AuthLayout`을 사용한다. 로그인 전 사용자가 접근하는 화면이다.

### 앱 라우트

`/dashboard`, `/transactions`, `/category`는 `ProtectedRoute`와 `AppShellLayout`을 거친다.

진입 시 처리:

1. 메모리에 access token이 있으면 화면을 렌더링한다.
2. access token이 없으면 refresh token으로 세션 복구를 시도한다.
3. 복구 성공 시 화면을 렌더링한다.
4. 복구 실패 시 로그인 화면(`/`)으로 이동한다.

## 로그인 화면

| 항목 | 내용 |
| --- | --- |
| Route | `/` |
| 목적 | 이메일/비밀번호로 로그인한다. |
| 주요 API | `POST /api/auth/login` |
| 성공 시 | access token 저장 후 인증 화면으로 이동 |

### 입력 항목

| 항목 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| 이메일 | text | 예 | 사용자 이메일 |
| 비밀번호 | password | 예 | 사용자 비밀번호 |

## 회원가입 화면

| 항목 | 내용 |
| --- | --- |
| Route | `/signup` |
| 목적 | 신규 사용자를 등록한다. |
| 주요 API | `POST /api/auth/register` |
| 성공 시 | 회원가입 완료 후 로그인 또는 후속 화면으로 이동 |

### 입력 항목

| 항목 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| 이메일 | text | 예 | 로그인 ID |
| 비밀번호 | password | 예 | 계정 비밀번호 |
| 이름 | text | 예 | 사용자 이름 |

### 시스템 처리

회원가입 성공 시 백엔드에서 기본 가계부와 기본 분류 `INCOME`, `EXPENSE`가 자동 생성된다.

## 대시보드 화면

| 항목 | 내용 |
| --- | --- |
| Route | `/dashboard` |
| 목적 | 현재 선택 기간의 가계 흐름을 요약한다. |
| 주요 API | `GET /api/transactions`, `GET /api/stat`, `GET /api/stat/period`, `GET /api/categories` |

### 주요 영역

| 영역 | 설명 |
| --- | --- |
| 요약 히어로 | 순잔액, 총수입, 총지출 표시 |
| 기간 선택 | 월 기준/연도 기준 선택 |
| 요약 카드 | 전체 거래 건수, 활성 카테고리 수, 통계 반영 개월 수 |
| 기간별 추이 | 기간별 수입/지출 통계 차트 |
| 수입/지출 비중 | 수입 합계와 지출 합계 비교 |
| 최근 거래 | 최근 거래 최대 5건 |
| 주요 카테고리 | 거래 사용량 기준 상위 카테고리 최대 6개 |

### 기간 선택 규칙

| 모드 | 처리 |
| --- | --- |
| 월 기준 | 선택 연월의 시작일~종료일을 조회 범위로 설정 |
| 연도 기준 | 선택 연도 1월 1일~12월 31일을 조회 범위로 설정 |

### 상태

| 상태 | 처리 |
| --- | --- |
| Loading | 대시보드 로딩 상태 표시 |
| Error | 에러 메시지와 재시도 버튼 표시 |
| Empty | 차트 또는 목록별 빈 상태 메시지 표시 |

## 거래 내역 화면

| 항목 | 내용 |
| --- | --- |
| Route | `/transactions` |
| 목적 | 거래를 조회하고 관리한다. |
| 주요 API | `GET /api/transactions`, `POST /api/transactions`, `GET /api/transactions/{id}`, `PUT /api/transactions/{id}`, `DELETE /api/transactions/{id}`, `GET /api/stat`, `GET /api/stat/period` |

### 주요 영역

| 영역 | 설명 |
| --- | --- |
| 기간 필터 | 시작일, 종료일 선택 |
| 거래 추가 버튼 | 거래 생성 모달 열기 |
| 수입/지출 파이 차트 | 선택 기간의 유형별 통계 표시 |
| 기간별 막대 차트 | 수입/지출 추이 표시 |
| 거래 목록 | 거래 목록 표시 및 상세 모달 진입 |

### 거래 생성 모달

| 항목 | 설명 |
| --- | --- |
| 분류 | 현재 가계부의 `INCOME`, `EXPENSE` 중 선택 |
| 금액 | 0보다 큰 숫자 |
| 카테고리 | 카테고리 목록에서 선택 |
| 설명 | 선택 입력 |
| 거래일시 | 날짜/시간 선택 |

처리 흐름:

1. 모달이 열리면 현재 가계부의 분류와 카테고리를 조회한다.
2. 사용자가 필수값을 입력한다.
3. 거래 생성 API를 호출한다.
4. 성공 시 거래 목록과 통계 데이터를 새로고침한다.

### 거래 상세 모달

| 기능 | 설명 |
| --- | --- |
| 상세 조회 | 선택한 거래 ID로 상세 정보를 조회한다. |
| 수정 진입 | 상세 모달에서 수정 모달을 연다. |
| 삭제 요청 | 확인 창 후 삭제 API를 호출한다. |

### 거래 수정 모달

기존 거래 정보를 폼에 표시하고 수정 API를 호출한다. 성공 시 거래 목록과 통계를 새로고침한다.

## 카테고리 관리 화면

| 항목 | 내용 |
| --- | --- |
| Route | `/category` |
| 목적 | 카테고리와 분류를 관리한다. |
| 주요 API | `GET /api/categories`, `POST /api/categories`, `PUT /api/categories/{id}`, `DELETE /api/categories/{id}`, `GET /api/classifications` |

### 탭

| 탭 | 설명 |
| --- | --- |
| 카테고리 | 사용자 카테고리 목록, 생성, 수정, 삭제 |
| 분류 | 현재 가계부 기준 분류 목록 조회 |

### 카테고리 생성 모달

| 모드 | 설명 |
| --- | --- |
| 개별 추가 | 이름, 설명, 색상을 입력해 하나 생성 |
| 빠른 일괄 추가 | 여러 줄에 입력한 이름을 한 번에 생성 |

개별 추가 옵션:

| 옵션 | 설명 |
| --- | --- |
| 계속해서 추가하기 | 생성 후 모달을 유지하고 다음 입력을 준비 |
| 색상 선택 | `ChromePicker`로 색상 선택 |

일괄 추가 규칙:

| 규칙 | 설명 |
| --- | --- |
| 빈 줄 무시 | 내용 없는 줄은 제외 |
| 중복 제거 | 같은 이름은 한 번만 생성 |
| 색상 자동 지정 | 각 카테고리에 랜덤 색상 부여 |

### 카테고리 수정

카테고리 목록에서 수정할 항목을 선택해 이름, 설명, 색상을 변경한다.

### 카테고리 삭제

삭제 시 대체 카테고리를 선택해야 한다. 삭제 대상 카테고리를 참조하던 거래는 대체 카테고리로 이동된 뒤 카테고리가 삭제된다.

### 분류 탭

현재 선택 가계부의 분류 목록을 표시한다. 기본 분류는 회원가입 시 생성되는 `INCOME`, `EXPENSE`이다.

## 가계부 선택

`AccountBookProvider`가 앱 전역에서 가계부 목록과 현재 선택 가계부를 관리한다.

| 규칙 | 설명 |
| --- | --- |
| 목록 없음 | 현재 선택 가계부를 `null`로 설정 |
| 선택 가계부가 목록에 있음 | 기존 선택 유지 |
| 선택 가계부가 없거나 사라짐 | 첫 번째 가계부를 기본 선택 |

## 공통 API 클라이언트 동작

| 동작 | 설명 |
| --- | --- |
| Base URL | `VITE_API_TRANSACTION_BASE_URL` 또는 `http://localhost:10003/api` |
| 인증 헤더 | access token이 있으면 `Authorization` 헤더 자동 추가 |
| 응답 unwrap | `ApiResponse<T>`에서 `data`를 추출 |
| 실패 응답 | `code`가 `S`로 시작하지 않으면 `ApiClientError` 발생 |
| 401 처리 | refresh token으로 재발급 후 원 요청 재시도 |
