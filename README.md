# 🌿 소담 (Sodam)

> **가볍게 기록하고, 나만의 소비 습관을 쉽게 파악하는 개인 맞춤형 가계부 웹 서비스**

---

## 🧭 프로젝트 개요

요즘 구독료, 택시비, 커피값…
소비는 소소하지만, 그게 쌓이면 통장은 금방 말라버립니다.

가계부 앱을 써보려 했지만,
> "입력은 귀찮고, 통계는 어렵고, 인사이트는 부족하다."

그래서 만들기로 했습니다.
**지출 데이터를 중심으로 습관까지 정리해주는, 개인 맞춤형 소비 관리 웹 서비스**입니다.

---

## ✨ 주요 기능

- **📥 간편한 소비 기록**: 모바일 최적화, 빠른 입력, 오프라인 상태에서도 기록 후 재접속 시 자동 동기화
- **🏷 카테고리/태그 분류**: 다건 선택, 카테고리별 필터링
- **📊 소비 분석 시각화**: 예산 대비 실제 지출(도넛/바 차트), 카테고리별·월별 통계, 구성원별 통계
- **💰 예산 & 반복 거래 관리**: 월간 예산 설정, 반복 지출/수입 자동 등록
- **🏦 자산 관리**: 계좌·자산 등록 및 거래에 따른 잔액 자동 보정
- **👤 게스트 모드**: 로그인 없이 로컬에서 먼저 사용해보고, 이후 회원가입 시 데이터 이관 가능

---

## 🛠 기술 스택

| 영역       | 기술                                                             |
|------------|------------------------------------------------------------------|
| Frontend   | React 19, TypeScript, Vite, MUI (Material UI), Emotion            |
| 상태/데이터 | Supabase (Auth + Postgres, `@supabase/supabase-js`), axios        |
| 오프라인   | 로컬 캐시 + 오프라인 큐 동기화, 게스트 모드(localStorage)           |
| Deploy     | Vercel                                                            |

이 저장소는 별도의 백엔드 서버 없이, **Supabase를 단일 백엔드**로 사용하는 프론트엔드 단일 레포로 구성되어 있습니다. 인증(Auth)과 도메인 데이터(거래·카테고리·예산·자산 등) 모두 Supabase 클라이언트로 직접 접근하며, 접근 제어는 Row Level Security(`supabase_rls.sql`, `supabase_setup.sql` 참고)로 처리합니다.

## 🚀 시작하기

```bash
npm install
npm run dev
```

`.env`에 아래 환경 변수가 필요합니다.

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

자세한 아키텍처와 개발 가이드는 [CLAUDE.md](./CLAUDE.md)를 참고하세요.
